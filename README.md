# BMB · יומן עבודה

<img src="icons/icon-192.png" width="72" align="right" alt="BMB">

יומן עבודה יומי למנהל עבודה באתר בנייה – **Ben Menachem Bari**.
אפליקציית ווב סטטית (HTML/CSS/JS), מותאמת לאייפון, עברית RTL, עובדת גם בלי אינטרנט.

**לפתיחה:** https://benkehati26-pixel.github.io/bmb/

## מה יש באפליקציה
- **יומן יומי** – תאריך, אתר, נוכחים (פועלים / קבלני משנה / ציוד), עבודות שבוצעו, הערות, שעות (התחלה/סיום + סה״כ), מזג אוויר.
- **שמירה אוטומטית** במכשיר (localStorage) לפי תאריך. היסטוריה – פתיחה, עריכה, מחיקה. גיבוי וייבוא JSON.
- **ייצוא לאקסל (.xlsx)** – טבלה מסודרת: ריכוז יומי, פירוט לפי קבלן עם סיכומי ביניים וסה״כ כללי, סיכום קבלנים; עם לוגו חברת הבנייה ו-BMB. ליום אחד או לטווח (שבוע / חודש / מותאם / הכל). עובד גם אופליין (ExcelJS מקומי ב-vendor/).
- **שליחה לוואטסאפ** כטקסט מסודר, שיתוף, העתקת טקסט, הדפסה / PDF עם הלוגו.
- **עוזר AI** – כותבים חופשי, ה-AI מנסח יומן מקצועי, מציג תצוגה מקדימה, וממלא את הטופס רק אחרי "אשר ומלא".

## הגדרת מפתח AI (פעם אחת בכל מכשיר)
1. יוצרים מפתח ב-https://console.anthropic.com/settings/keys
2. באפליקציה: **הגדרות ⚙️ ← מפתח Anthropic API** ← מדביקים ← **שמור מפתח** ← **בדוק חיבור**.

המפתח נשמר **רק במכשיר** (localStorage) ונשלח ישירות ל-api.anthropic.com. אין שום מפתח בקוד או במאגר.

## התקנה באייפון
Safari ← כפתור שיתוף ⬆️ ← **הוסף למסך הבית**.

## פיתוח
אין build. מריצים שרת סטטי: `python3 -m http.server` ופותחים http://localhost:8000
