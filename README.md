# BMB · יומן עבודה

<img src="icons/icon-192.png" width="72" align="right" alt="BMB">

יומן עבודה יומי למנהל עבודה באתר בנייה – **Ben Menachem Bari**.
אפליקציית ווב סטטית (HTML/CSS/JS), מותאמת לאייפון, עברית RTL, עובדת גם בלי אינטרנט.

**לפתיחה:** https://benkehati26-pixel.github.io/bmb/

## מה יש באפליקציה
- **יומן יומי** – תאריך, אתר, נוכחים (פועלים / קבלני משנה / ציוד), עבודות שבוצעו, הערות, שעות (התחלה/סיום + סה״כ), מזג אוויר.
- **שמירה אוטומטית** במכשיר ובענן (Supabase) לפי תאריך. היסטוריה – פתיחה, עריכה, מחיקה. גיבוי וייבוא JSON.
- **ייצוא לאקסל (.xlsx)** – טבלה מסודרת: ריכוז יומי, פירוט לפי קבלן עם סיכומי ביניים וסה״כ כללי, סיכום קבלנים; עם לוגו חברת הבנייה ו-BMB. ליום אחד או לטווח (שבוע / חודש / מותאם / הכל). עובד גם אופליין (ExcelJS מקומי ב-vendor/).
- **שליחה לוואטסאפ** כטקסט מסודר, שיתוף, העתקת טקסט, הדפסה / PDF עם הלוגו.
- **עוזר AI** – כותבים חופשי, ה-AI מנסח יומן מקצועי, מציג תצוגה מקדימה, וממלא את הטופס רק אחרי "אשר ומלא".

## חשבונות והרשאות (v1.2)
- **כניסה עם שם משתמש וסיסמה** (Supabase Auth). שם משתמש בלי `@` ממופה פנימית ל-`<username>@bmb.local`; המנהל יכול להיכנס גם עם `ben` וגם עם המייל.
- **אין הרשמה עצמית** – רק המנהל יוצר משתמשים (מסך 👥 משתמשים): יצירה, איפוס סיסמה, השבתה, הפעלת/כיבוי עוזר AI.
- **מנהל בלבד** משנה את פרטי החברה (שם + לוגו) ורואה את היומנים של כל המשתמשים. משתמש רגיל רואה ועורך רק את היומנים שלו. האכיפה ב-RLS של Postgres, לא רק בממשק.
- **סנכרון**: היומנים נשמרים במכשיר ומסתנכרנים לענן כשיש חיבור (עובד גם אופליין). בכניסה הראשונה מוצע להעלות יומנים ישנים מהמכשיר.
- **📷 תמונות לעוזר (v1.3)** – בצ׳אט: צלם / מהגלריה, עד 4 תמונות להודעה (מוקטנות ל-1600px JPEG במכשיר). ה-AI קורא תעודות משלוח, עבודה באתר, ציוד ופתקים בכתב יד וממלא את היומן אחרי אישור. אפשר לצרף את התמונות ליומן של היום (Supabase Storage פרטי – רק הבעלים והמנהל רואים) והן נשלחות בוואטסאפ כקישור תקף ל-7 ימים.
- **עוזר AI** רץ בשרת (Edge Function `ai` → Google Gemini, מודל flash חינמי) – אין מפתח במכשיר. מגבלה: 50 בקשות למשתמש ליום.

קוד השרת: `supabase/migrations/001_init.sql` (טבלאות + RLS), `002_photos.sql` (bucket תמונות + RLS), `supabase/functions/ai`, `supabase/functions/admin-users`.
אין שום סוד במאגר – רק המפתח הציבורי (publishable) של Supabase. מפתח Gemini ו-service_role שמורים כ-secrets של ה-Edge Functions.
